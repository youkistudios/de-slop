# Security Policy

de-slop is a Markdown instruction file. It has no runtime service, credential
store, network client, or installer. Its main risk is behavioral: an
over-broad edit that changes what a draft says rather than how it reads.

## Supported version

Security fixes target the latest release on `main`.

## Reporting

Please use GitHub private vulnerability reporting when available. Otherwise,
contact the maintainer privately before publishing exploit details. Do not put
credentials, private drafts, or personal data in a public issue.

## Operator responsibilities

- Review the de-slopped output against the original before publishing it.
- Treat the audit as advisory; the skill does not verify facts or claims in
  the draft, only removes named surface patterns.
- Keep unpublished manuscripts and other sensitive drafts out of public
  issues, discussions, or examples when reporting a problem.

No skill invocation is authorized to publish, delete, or overwrite a draft on
the author's behalf merely because de-slop was run on it.
